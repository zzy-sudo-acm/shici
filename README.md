# 拾词

输入忘记的单词，回车记一笔。相同单词会累计遗忘次数。

## 使用

- **记一笔**：首页只保留单词输入和记录动作，支持大小写归一、英文短语、撤销。
- **词本**：按遗忘次数排序，忘记 3 次及以上的词归入「顽固词」。点击词条可补充词义、音标、助记或修改拼写。
- **复习**：先主动回忆，再显示词义。到期后记得，依次在 1、3、7、14、30、90 天后复习；忘记后 10 分钟重试。连续记得 5 次进入「已记住」，仍定期复习。提前练习成功不推进阶段或更改到期时间。
- **备份**：导出 JSON 或合并导入。重复导入不会累加遗忘次数。

词本保存在当前浏览器的 localStorage。手机和电脑不会自动同步，清理站点数据会清空词本，请定期导出。内置少量常见词的中文词义，其他词可手动补充。朗读使用浏览器和系统的英文语音。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。

```sh
npm test
npm run check
```

## GitHub Pages

静态文件位于 `docs/`，Pages 发布源设置为 `main` 分支的 `/docs` 目录即可，无需构建。资源使用相对路径，兼容项目子目录。

## 设计

遵循用户要求的输入优先、留白和有实际用途的控件；没有固定标语、仪表盘或演示数据。页面支持移动端、键盘操作、减少动画与语义化状态反馈。
