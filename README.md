# 拾词

输入忘记的单词，回车记一笔。相同单词会累计遗忘次数。

## 使用

- **记一笔**：输入两个及以上英文字母会显示带中文释义的候选，点选即可补全并记录；支持方向键与回车。直接输入完整单词回车也会自动查义。支持大小写归一、英文短语、撤销。
- **词本**：按遗忘次数排序，忘记 3 次及以上的词归入「顽固词」。点击词条可补充词义、音标、助记或修改拼写。
- **复习**：先主动回忆，再显示词义。到期后记得，依次在 1、3、7、14、30、90 天后复习；忘记后 10 分钟重试。连续记得 5 次进入「已记住」，仍定期复习。提前练习成功不推进阶段或更改到期时间。
- **备份**：导出 JSON 或合并导入。重复导入不会累加遗忘次数。

词本保存在当前浏览器的 localStorage。手机和电脑不会自动同步，清理站点数据会清空词本，请定期导出。内置约 5.9 万词的英汉补全词库，自动填充词义和音标，保留用户编辑过的词义；未收录的词仍可记录。朗读使用浏览器和系统的英文语音。

词库源自 [ECDICT](https://github.com/skywind3000/ECDICT)，按 MIT 许可分发，原始许可位于 `docs/dictionary/LICENSE-ECDICT.txt`，固定来源版本和数据摘要见 `docs/dictionary/source.json`。执行 `python scripts/build-dictionary.py` 可从固定版本重建；词库按首字母加载，不影响首页初次加载，也无需第三方查询服务。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。

```sh
npm test
npm run check
```

## GitHub Pages

静态文件位于 `docs/`，Pages 发布源设置为 `main` 分支的 `/docs` 目录即可，无需构建。资源使用相对路径，兼容项目子目录。

## 设计

遵循用户要求的输入优先、留白和有实际用途的控件；没有固定标语、仪表盘或演示数据。页面支持移动端、键盘操作、减少动画与语义化状态反馈。
